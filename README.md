# Responsive Landing Page

## About
This project is a responsive product landing page developed as part of the CodeOrbit Tech Web Development Internship.

The page promotes a fictional concept brand called Form/Flow, focusing on simple design and an improved everyday experience.

## Features
- Responsive header and navigation
- Hero section with call-to-action
- Product features section
- Brand story section
- Interactive button using JavaScript
- Responsive layout for desktop and mobile screens

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Resize the browser to test the responsive layout.

## Project Structure
- index.html — page structure and content
- style.css — styling and responsive design
- script.js — interactive button functionality
